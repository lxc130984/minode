# 06 · UI 规范：字符风与 Lisp 式渲染

本篇是视觉与交互的实现规范，精确到色值与间距。树布局（**Lisp 式渲染**：完全纵向
大纲 + 括号 + 悬挂缩进，D-29/D-30/D-31）是本作的识别性特征，实现时**逐字对照本篇**。

## 1. 基调：字符即 UI

终端 / 电传打字机审美：界面看起来像「用字符渲染出来的程序」。

1. **控件即文本**：按钮就是一段文本；状态变化靠前景/背景反色表达，不靠形状变化。
2. **符号承担语义**：括号 `( )`（表达式边界 + 拖把手 + 折叠开关）、`…+N`（折叠徽标）、
   `[]`（返回值）、`[?]`（未命中）、`×`（回收）、`▣`（可开窗）。不引入图标库/emoji/插图。
3. **宽度即内容宽度**：行内控件 `white-space: nowrap`，不设 `min-width`。
4. **行距紧贴**：行内元素间距 2-4px，行间距 1-3px。信息密度优先。
5. 拖拽中空实参列表展开**幽灵实参槽**（虚线框，§5.4），提示只用字符级笔画表达。

## 2. 色板

| 用途                      | 色值                                                |
| ------------------------- | --------------------------------------------------- |
| 页面背景                  | `#0b0b10`                                           |
| 主文字                    | `#b9b9c2`                                           |
| 强调（hero 数值、满仓）   | `#f0f0f4` / `#e6e6ea`                               |
| 次要文字（标签、徽标）    | `#6f6f7a` / `#55555e`                               |
| 未识别（`[?]`、未知类型） | `#8a8a95`                                           |
| 留白占位（空态文字）      | `#3a3a44` / `#34343e`                               |
| 回收按钮（`×`）           | `#6f6f7a`（hover `#d6d6de`）                        |
| 边框 / 分隔线             | `#1d1d24`（容器）、`#26262e`、`#222229`             |
| hover 反色                | 背景 `#d6d6de` + 文字 `#0b0b10`                     |
| 拖拽预览（ghost）         | `opacity: 0.35`                                     |
| 拖拽准备（chosen）        | 背景 `#2c2c36`（只作用于直接 chip）                 |
| 缩进标线                  | `rgba(230, 230, 234, 0.055)` 1px（极浅，D-31）      |
| 括号配对高亮              | 底 `#2c2c36` + 字 `#e6e6ea`（D-31）                 |
| 幽灵实参槽                | 虚线框 `#3a3a44` + 底 `rgba(11,11,16,0.55)`（D-31） |

无渐变、无阴影、无圆角（`border-radius` 一律 0）。

### 2.1 语法高亮（种类决定色相，深度只决定亮度）

| 种类                      | 判定                         | 色相      | 字重 |
| ------------------------- | ---------------------------- | --------- | ---- |
| 函数 `k-machine`          | `recipesFor().length > 0`    | `#e6b04f` | 500  |
| 符号 `k-symbol`           | 无配方的类型 / 物品行        | `#5fc3a6` | 400  |
| 工具 `k-tool`             | `ItemDef.toolClass`          | `#b98fe0` | 400  |
| 未注册 `k-unknown`        | 注册表里没有这个 type        | `#8a8a95` | 400  |
| 结果 `[..]`               | 命中配方                     | `#94d47f` | 继承 |
| 未解析 `[?]`              | 配方未命中                   | `#e09a6a` | 继承 |
| 方括号 `[ ]` / 括号 `( )` | `.chip-bracket` / `.bracket` | `#7c7c85` | 继承 |

实现要点：`--ink-base`（种类色相）挂 `.chip`，`--dim`（深度衰减）挂 `.node[data-depth]`；
最终色 = `color-mix(in oklab, var(--ink-base), #0b0b10 var(--dim))`。
⚠️ **`color-mix()` 百分比不能写 `calc()`**（整条声明静默失效）；括号/预览元素不在
`.node` 内，需自带 `--dim: 0%`。深度衰减 2/3/4/5/6+ 层 = 8/15/22/28/34%。

## 3. 字体与字号

```css
:root {
  color-scheme: dark;
  font-family: ui-monospace, 'Cascadia Code', 'Source Han Mono SC', monospace;
  font-size: 13px; /* 正文基准 */
  line-height: 1.5;
}
```

- **必须等宽**；中文回退 CJK 等宽。三档字号：26px（hero）、13px（正文）、11-12px（角标/标签）。
- 数字格式（`utils/format.ts`）：<1000 直接显示；≥1000 科学计数 `1.23e6`。

## 4. 树布局：Lisp 式渲染（核心）

### 4.1 结构（D-30/D-31：完全纵向大纲，emacs 风格）

```
( 发动机厂[引擎]
   ( 装配台[零件]
      ( 轧机[板] …+10 )
      ( 冶炼炉[铁]
         铁矿石
         煤炭
         氧气 )
      … )
   ( 锻炉[钢] … ) )
```

- **完全纵向**：每个表达式 = `( 头部` 一行 + 实参逐行 + 子树尾部闭括号行；
- **悬挂缩进 21px/层**（`margin-left: 13px + padding-left: 8px`）+ **极浅缩进标线**
  （`rgba(230,230,234,0.055)` 1px，编辑器低对比度惯例，D-31）——嵌套由
  「括号 + 缩进」表达；
- **宽度有界**（深度×21px + chip），高度随内容增长、随页面滚动；
- **括号规则**见 01 篇 §1.1；**自动折叠（D-28）**：默认只展开前 2 层
  （`FOLD_DEPTH = 2`），大子树落到第 3 层及以下自动折叠；调试面板有「全部折叠/展开全部」。

### 4.2 CSS 关键值

```css
.root-list {
  min-height: 160px;
  padding: 6px 8px;
  border: 1px solid #1d1d24;
}
.root-list:empty::before {
  content: 'empty';
  color: #3c3c46;
}
.node {
  position: relative; /* 幽灵实参槽/预览用绝对定位（不参与布局） */
  padding: 1px 0;
}
.node-row {
  display: flex;
  align-items: center;
  gap: 3px;
}
.kids {
  margin: 1px 0 1px 13px;
  padding-left: 8px;
  border-left: 1px solid rgba(230, 230, 234, 0.055); /* 极浅缩进标线 */
  min-height: 20px;
}
.kids:empty {
  /* 空子列表平时零尺寸（无噪声） */
  min-height: 0;
  margin: 0;
  padding-left: 0;
  border-left-color: transparent;
}
```

- **层级缩进**：`.kids` 的 `margin-left + padding-left + border-left` 表达一层深度（21px）；
- **顺序 = `children` 数组顺序**，拖拽即重排、即编辑实参顺序；**没有任何自动排序**。

### 4.3 深度着色

层级越深，墨色越淡（层级竖线同层加深一档）：

| 深度 | `--dim` | 层级竖线  |
| ---- | ------- | --------- |
| 1    | 0%      | `#2c2c36` |
| 2    | 8%      | `#26262e` |
| 3    | 15%     | `#212129` |
| 4    | 22%     | `#1d1d24` |
| 5    | 28%     | 同 4      |
| 6+   | 34%     | 同 4      |

## 5. 交互态与动画

### 5.1 括号（D-29/D-30/D-31）

- **拖拽把手**：拖 `(`/`)` = 移动整棵子表达式（`.chip, .bracket-open, .bracket-close`）；
- **折叠开关**：点 `(`/`)` = 折叠/展开（折叠形态完整保留 `( 头部[ret] …+N )`）；
  点 `…+N` 徽标 = 展开；无独立按钮；
- **配对高亮**（emacs show-paren 悬停版）：悬停任一端 → 两端同时亮
  （`.bracket-matched`：底 `#2c2c36` + 字 `#e6e6ea`）；hover 本体反色照常；
- 放置模式下括号左键放行（冒泡给树区 = 建造）。

### 5.2 点击反馈（pulse）

`chip.pulse`：0% 反色 → 100% 透明，0.35s ease-out，只作用于产出成功的表达式。
实现纪律见 02 篇 §7（按节点 id 分键 + 先清空一帧再挂回）。

### 5.3 入场动画（D-31）

`place` 建造 / 拖拽落位成功的表达式播放一次 `node-appear`：整式 180ms 淡入下沉；
闭括号行额外 240ms 从上滑入（读作「括号合上」）。标记按节点 id 分键，260ms 自清
（`feedback.ts`）。

### 5.4 幽灵实参槽（D-31）

拖拽/放置悬停空实参列表 → 虚线框空槽（76×18，chip 同款比例）——绝对定位不参与布局
（不回流），位于行下方；一旦节点插入，列表不再 `:empty`、槽消失。

### 5.5 放置模式视觉层（PlacementGhost.vue）

- 光标跟随一个**普通样式的 chip**（`.place-cursor`，opacity 0.9）；
- 落点预览 = `.place-ghost`（opacity 0.35，同 `sortable-ghost`）**真实插入目标列表**，
  兄弟节点自然挤开，带 **120ms FLIP**（WAAPI，与容器 `:animation="120"` 同款）；
  ghost 是命令式管理的外来 DOM：落点没变不动 DOM、树重渲染后按实际位置自检、
  真实拖拽开始时立即摘除（SortableJS 的列表项映射不被污染）；
- **边缘自动滚动**：指针停在视口上下边缘 60px 内 → rAF 循环滚页面（14px/帧），
  每帧重算落点。

## 6. 交互态规范

| 状态            | 表达                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------- |
| hover（可点区） | 前景/背景互换，无过渡或极短过渡                                                             |
| 拖拽准备        | **只有**被拖节点的直接 chip：`.sortable-chosen > .node-row > .chip { background: #2c2c36 }` |
| 拖拽预览        | `.sortable-ghost { opacity: 0.35 }`                                                         |
| 悬停标记        | 只给被悬停节点的**父节点** chip 加下划线（`#e6e6ea` 2px offset 4px，D-04）                  |
| 括号配对        | 悬停括号 → 两端 `.bracket-matched`                                                          |
| 折叠            | `( 头部[ret] …+N )` 完整括号形态（无独立按钮）                                              |

## 7. 折叠与空态

| 情形       | 表达                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 折叠       | `( 头部[ret] …+N )`；`.kids` 不渲染（`v-if` 级卸载 → 结构上不可拖入） |
| 根列表为空 | `empty`（`:empty::before`，接近背景色）                               |
| 子列表为空 | 平时零尺寸（无噪声）；**拖拽/放置中**展开为幽灵实参槽（§5.4）         |
| 未注册类型 | 名称显示 `?`，不可求值，可拖拽/回收                                   |

┌ 节点（选择面板）       ┐ ┌ 主区（树区）─────────────┐

### 8.1 浮动窗口（箱子）

点击树上带 `panel` 的节点 → 树区蒙灰（不可交互，点灰层关闭），主区左缘浮出窗口
（`width: min(560px, 74%)`、`max-height: 60vh`、标题栏原生指针拖动）；
内容 = 与背包同款的物品行；容量显示在标题栏。

## 9. 拖拽实现参数（vue-draggable-plus）

| 参数                     | 树根 `.root-list` / 子 `.kids`             |
| ------------------------ | ------------------------------------------ |
| 数据绑定                 | `:model-value`（**树只读它渲染，不写回**） |
| `group`                  | `{ name: 'nodes' }`（只有树是可拖列表）    |
| `handle`                 | `.chip, .bracket-open, .bracket-close`     |
| `draggable`              | `'.node'`（括号 span 不是列表项）          |
| `empty-insert-threshold` | 根 `30` / 子 `8`                           |
| `on-move`                | `guardCycle`（防环）                       |
| `on-start` / `on-end`    | `setDragging(true)`；`end` → `handleDrop`  |

背包/箱子（物品行列表）**不是** Sortable 容器。落位走 `handleDrop`（plan 优先 +
指针兜底，05 篇 §2.1）。

坑清单（全部踩过，直接复用经验）：

1. **防环用 DOM 包含判断**（`!evt.dragged.contains(evt.to)`），守卫接口 duck-typing
   便于无 DOM 单测；数据层再加两道校验。
2. **落位不能读 DOM 顺序**：vue-draggable-plus 在 `on-end` 之前已把 DOM 复位。
3. **跨列表 drop 可能不触发**：SortableJS 的 plan 会退回源列表——指针只在此时兜底；
   合成事件流里 dragend 坐标不可信，别让指针无条件覆盖 plan。
4. **外来元素立即摘除**：放置 ghost 在真实拖拽开始时必须摘掉，否则 SortableJS 把它
   当列表项。
5. **拖拽结束立刻 click 可能被吞**：括号折叠的点击在真实浏览器正常（合成输入除外）。
6. **`sortable-chosen` 高亮只作用于直接 chip**（禁止后代选择器，否则整棵子树闪烁）。

## 10. 反模式清单（禁止出现）

- 圆角、盒阴影、渐变、彩色遮罩、任何 `border-radius`；
- 图标库、emoji、插图、logo；
- `min-width`/`max-width` 撑出的「卡片感」；居中文本块（hero 除外）；
- chip 类控件内边距 > 3px、行内间距 > 4px；
- 过渡/动画长于 0.4s；弹窗/遮罩/抽屉（一律用 `<details>` 或行内反色替代）。
