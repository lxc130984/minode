# minode-beta 设计文档

一套「节点树 = S 表达式」增量沙盒游戏的实现规范。机制与架构的**唯一事实源**；
实现代码与这些文档必须同步演进（见 05 篇 §9）。

## 一句话

父节点是函数、子节点是实参、点击 = 求值子树、返回值沿树向上流动；
节点是沙盒里的方块，物品是它背包里的形式。

```
冶炼炉[铁]<3/10>
  铁矿石<5/64>  煤炭<2/64>  氧气<1/64>
```

## 本作与 minode-alpha 的关系

- **借鉴**：alpha 的 UI 美术规范与布局排序算法、拖拽实战坑清单、
  「效果原语 + 内容包」的数据化哲学、Decimal 纪律。这些经验经实践检验，直接复用。
- **不借鉴**：alpha 的引擎核心（身份=子节点多重集、两跳点击派发）——
  本作是「父=函数、子=参数、点击=求值」的求值模型；
  也不用模块级可变注册表、不设「无背包」前提。
- alpha 的失败根因在仓库内没有复盘记录（已穷尽检查）；本作的替代方案是
  「规范文档化 + 里程碑验收」，不猜测性复刻。

## 当前进度

纯表达式语义已落地：**点击 = 单节点 eval**（符号无响应、函数命中配方即产出物品进背包），
**手持 = 隐式实参**参与点击检测（手持斧头点森林 → 木材，D-25），
结果静态计算（结构变更时「受影响节点 + 祖先链」增量重算）。
**生产线模型（D-26/D-27）**：资产只有物品（背包，容量受限）——选择面板选类型 → 放置模式
（虚影 + FLIP 挤压预览 + 连续建造）→ 左键消耗物品建造；`×`/拖到侧栏回收分解成原材料
（默认 30% 返还）；箱子是物品容器。树为**纵向大纲**布局（缩进式，默认展 2 层自动折叠，D-28）。引擎 + 83 个单测、六层加工链 + 矿井 + 森林/斧头、
树渲染/折叠（语法高亮）、树内拖拽（零回流 + 单写者落位）、localStorage 存档（v4）、
撤销树（分叉 + 穿梭，07 篇 §4.4）。
性能基线：400 节点点击到下一帧 ≈ 1 帧（反馈状态按节点分键，02 篇 §7）。

## 快速上手（开发者）

```sh
vp install          # 安装依赖
vp dev              # 开发服务器
vp check            # 格式 + lint
vp run type-check   # 类型检查（vue-tsc，必跑：vp check 不检查 .vue 脚本）
vp test             # 单元测试（vitest 由 Vite+ 内置）
vp run build        # 类型检查 + 生产构建
```
