# minode-beta 设计文档

一套「节点树 = S 表达式」增量游戏的实现规范，机制与架构的**唯一事实源**；
实现代码与这些文档必须同步演进（纪律见 05 篇 §9）。术语的唯一事实源是
[10 篇术语表](10-glossary.md)。

## 一句话

**节点就是 symbol，嵌套就是括号，`()` 表示 eval**；
资产只有物品（背包），节点由建造产生、由回收销毁——两者只在建造/回收处兑换。

```
( 发动机厂[引擎]
   ( 装配台[零件]
      ( 轧机[板] …+10 )
      ( 冶炼炉[铁]
         铁矿石
         煤炭
         氧气 )
      … )
   ( 锻炉[钢] … ) )
```

## 与 minode-alpha 的关系

- **借鉴**：字符风 UI 美术、拖拽实战坑清单、「效果原语 + 内容包」的数据化哲学、
  Decimal 纪律。
- **不借鉴**：alpha 的引擎核心（身份=子节点多重集、两跳点击派发）、模块级可变注册表。
- alpha 的失败根因在仓库内没有复盘记录；本作的对策是「规范文档化 + 里程碑验收 +
  ADR 台账」，不猜测性复刻。

## 快速上手（开发者）

```sh
vp install          # 安装依赖
vp dev              # 开发服务器
vp check            # 格式 + lint
vp run type-check   # 类型检查（vue-tsc，必跑：vp check 不检查 .vue 脚本）
vp test             # 单元测试（vitest 由 Vite+ 内置）
vp run build        # 类型检查 + 生产构建
```

推送到 `main`/`master` 自动部署 GitHub Pages（`.github/workflows/deploy.yml`）。
