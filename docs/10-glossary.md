# 10 · 术语表（唯一词汇事实源）

本表是全项目（文档 / 代码 / UI 文案 / 提示语）的**唯一术语来源**。

使用规则：

1. 新文档、新代码、新 UI 文案只允许使用本表词条；要引入新概念，**先入表再用**；
2. 代码标识符与术语一一对应（§5 对照表），改名先改本表；
3. §6 的废弃词不得出现在新代码与新文档（08 篇 ADR 的历史记述除外）。

---

## 1. 表达式层（游戏的本体）

整个游戏同构于 Lisp 的 s 表达式：**节点就是 symbol，嵌套就是括号嵌套**。

| 术语           | 代码标识符                         | 定义                                                                                                                                            |
| -------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 表达式         | `GameNode` 子树                    | `(头部 实参…)`：一个节点 + 它的子节点构成的整体，同构于 `(f a b)`                                                                               |
| 节点           | `GameNode`                         | 表达式的最小单元：类型 + 实参（子节点）+ 返回值（`[]`）。节点就是 symbol                                                                        |
| 节点类型       | `NodeTypeId` / `NodeDef`           | 注册表条目（Lisp 里的「名字」）；定义在内容包，id 是存档契约                                                                                    |
| 函数（节点）   | `recipesFor(type).length > 0`      | 有配方的类型：自己的 `(…)` 可点击求值并产出物品                                                                                                 |
| 符号（节点）   | 无配方                             | 没有配方的类型：返回值 = 自身（原子），**不渲染括号、点击无效果**，只作实参                                                                     |
| 括号           | `.bracket-open` / `.bracket-close` | 表达式的边界 token：`(` 在头部行首，`)` 在子树尾（折叠/空函数收在行内）；**开/闭括号都是拖拽把手 + 折叠开关**，悬停时配对高亮（D-29/D-30/D-31） |
| **求值 eval**  | `evalNode()`                       | **`()` 表示 eval**（D-30）：点击一个**表达式**（渲染括号的节点）= eval 它自己的 `(…)`；裸符号实参点击没有效果                                   |
| **返回值 ret** | `RetState` / 节点右侧 `[]`         | 表达式静态求值的结果，显示为 `name[值]`——写给玩家看的                                                                                           |
| 未命中         | `unresolved` / `[?]`               | **空手**配方检测不通过；手持某物时可能命中                                                                                                      |
| 配方           | `RecipeDef`                        | `(函数类型 × 实参签名) → 产物物品` 的映射，纯数据                                                                                               |
| 签名           | `childrenSignatureKey()`           | 实参返回值构成的**多重集**键（顺序无关、数量有关）——唯一匹配模式（D-36）                                                                        |
| **产物**       | `Yield` / 配方 `out`               | 配方输出：**全部是物品**，进背包。只在配方语境使用                                                                                              |
| **手持**       | `heldItem`（= 选中背包物品）       | 作为**隐式实参**参与点击检测：先试「手持 + 实参」签名，再回落空手签名（手持永不打断已有配方）                                                   |
| eval 不消耗    | —                                  | 节点是 symbol，eval 不消耗它；同一棵树可以无限点击                                                                                              |

## 2. 资产层（玩家拥有什么）

**资产只有一种：物品（item）。** 节点只存在于树上（它们是表达式，不是库存）。

| 术语           | 代码标识符           | 定义                                                                         |
| -------------- | -------------------- | ---------------------------------------------------------------------------- |
| **物品**       | `ItemDef` / `ItemId` | 背包里可数的东西（铁矿/铁/木材/斧头……），也是**建造节点的货币**              |
| 背包           | `bag` / `ItemStore`  | `物品 → 数量` 的表；容量按**总数量**计（`config.bagCapacity`），无槽位无堆叠 |
| 建造成本       | `NodeDef.cost`       | 放置一个节点消耗的物品列表                                                   |
| 原材料         | `ItemDef.raw`        | 分解（回收）的终点：铁矿/煤/氧/木材；非原材料沿「唯一产物配方」继续下钻      |
| 节点           | `GameNode`           | 表达式单元，只存在于树上；由建造产生、由回收销毁                             |
| 物品与节点同名 | `iron_ore` 等        | 同一 id 可以既是物品（背包里）又是节点类型（树上）：一体两面                 |
| 箱子           | `chestContents`      | 带内容的特殊节点（`NodeDef.panel = 'storage'`）：同款物品表 + 独立容量       |

## 3. 容器层（东西放在哪）

| 术语 | 代码标识符           | 定义                                                                            |
| ---- | -------------------- | ------------------------------------------------------------------------------- |
| 容器 | —                    | 存放物品的界面统称：背包、箱子。都是 `物品 → 数量` 的表，**无槽位、不参与拖拽** |
| 背包 | `bag`                | 侧栏常驻容器（容量 `bagCapacity`）；手持的来源                                  |
| 箱子 | `chestContents`      | 带内容的特殊节点；点击打开浮动窗口；容量 `chestCapacity`                        |
| 转移 | `transferToChest` 等 | 容器之间的物品搬运：行单击 = 1 个、双击 = 整项；容量不够转能装下的部分          |

## 4. 交互层（玩家怎么操作）

生产线的核心循环：**选择面板选类型 → 放置模式（虚影）→ 左键建造 → 回收返还**。

| 术语         | 代码标识符                    | 定义                                                                                                   |
| ------------ | ----------------------------- | ------------------------------------------------------------------------------------------------------ |
| 选择面板     | `NodePalette.vue` / `palette` | 侧栏节点类型列表（名字 + 成本）；点击 = 进入/退出放置模式；付不起的暗淡                                |
| **放置模式** | `placing`                     | 光标挂着**虚影节点**的持续建造状态：左键 = 按落点建造；右键 / Esc / 再点同款 = 取消；可连续建造        |
| 虚影节点     | `PlacementGhost.vue`          | 跟随指针的建造预览（松手不消失）；树上同步显示落点 ghost（同 `sortable-ghost` 观感 + FLIP）            |
| 建造         | `place(type, owner, index)`   | 消耗 `cost` 在落点插入新节点（`payCost` 原子扣费；资源不足提示缺口）                                   |
| 回收         | `recycle(nodeId)`             | `×` 或拖到侧栏：移除节点（子节点上移），成本**分解成原材料**按返还率（默认 30%）折算返还；箱子内容原样 |
| 悬停         | `setHover`                    | 只给被悬停节点的**父节点**加下划线（键级更新，不全树重渲染）                                           |
| 折叠         | `toggleFold()` / `folded`     | **点开/闭括号折叠、点 `…+N` 徽标展开**（无独立按钮）；默认只展 2 层、落深处自动折叠                    |
| 浮动窗口     | `panel`                       | 箱子等点开的窗口（`NodeDef.panel` 是节点「可开窗」的能力字段；开窗会取消放置模式）                     |
| 树 / 主区    | `roots` / `.tree`             | 主界面的表达式树编辑区（**不叫「放置界面」**）                                                         |

## 5. 代码命名对照（术语 ↔ 标识符）

| 术语     | 标识符                                           | 说明                                                       |
| -------- | ------------------------------------------------ | ---------------------------------------------------------- |
| 节点     | `GameNode` / `createNode`                        | 只存在于树上                                               |
| 物品     | `ItemDef` / `ItemStore` / `bag`                  | `engine/bag.ts` 是物品库存纯函数层                         |
| 返回值   | `RetState` / `computeRet` / `normalizeTree`      | `ret` 字段                                                 |
| 产物     | `Yield { id, count }`                            | 曾用名 `ItemAmount`（已废弃）                              |
| 签名     | `childrenSignatureKey(children, mode, held?)`    | 第三参数 = 手持隐式实参                                    |
| 建造     | `place` / `startPlacing` / `placeAt`             | D-26/D-30                                                  |
| 回收     | `recycle(nodeId)`                                | 曾用名：收起 `stow` / `collapseToBag`（D-27 起带损耗分解） |
| 折叠     | `toggleFold(id)` / `node.folded`                 | 存档字段仍叫 `collapsed`（线上格式）                       |
| 转移     | `transferToChest` / `transferFromChest`          | D-26                                                       |
| 落点读取 | `readDrop` / `treeZoneAt` / `pointerOverSidebar` | DOM 层，`utils/tree-drop.ts`                               |
| 展示层   | `stores/display.ts`（纯函数）                    | nameOf / retOf / chipKind / costTextOf…                    |
| 反馈层   | `stores/feedback.ts`（瞬态）                     | pulse / hint / 悬停 / 配对高亮 / 入场                      |
| 示例局面 | `content/demo.ts`                                | 内容 id 只出现在 content/（D-32）                          |
| 箱子内容 | `chestContents`                                  | 曾用名 `containers`                                        |
