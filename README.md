# minode · 节点世界

一个"点击 + 增量 + 文字冒险"网页游戏:一切游玩元素皆**节点**,世界与背包是两棵同构的树。**点击节点行** = 折叠/展开,**拖拽** = 组织树,左侧的**触发按钮**(图标+名字)= 触发(做事需要**工作时间**,行底进度条填满才结算,忙碌中不能重复触发)。

> 🌐 在线游玩:<https://lxc130984.github.io/minode/>

## 玩法一瞥

- 点击**探索**节点的左侧按钮,有几率在它下面发现森林、河流等地形
- 点击**森林**的左侧按钮(空手)可以捡到木棍和石子,自动堆进背包
- **手工合成**节点天然生成在背包里:把材料堆整堆挂到它下面,点击即合成(如 3 石子 + 2 木棍 → 石斧)
- 把石斧放到世界里,再把森林拖到它下面,点击**石斧**的左侧按钮就会砍伐森林产出木头(石斧一次只对一棵树下手)
- 用木头合成**水车**并拖到河流下面,再把石斧挂到水车下面:水流会每 3 秒自动驱动石斧,木头持续进背包(一条河最多两台水车)
- 探索发现**山地**:石斧劈岩有几率挖到铜矿石;搭一座**篝火**把矿石挂在下面,选中「熔炼」配方点击篝火,矿石烧成**铜锭**
- 铜锭打造**铜镐**(挖矿必得)与**铜斧**(一次两根木头);**风车**不挑地方,立起来就每 5 秒驱动其下的工具——挂上铜斧就是自动柴场;最后竖起**图腾柱**,见证铜器时代
- 世界与背包之间**一次搬运一个**:整堆/整树不可跨区拖,放置与回收都是一条一条来
- 按**背包**节点的按钮开合背包分屏;世界与背包之间只能**单件互拖**(整堆/整树不可跨区)
- 背包里同类物品自动堆叠成一棵小树(显示前 4 个 + 省略号)
- 存档自动保存在浏览器本地,支持导出/导入 JSON

## 技术栈

Vue 3 + TypeScript + Pinia(持久化)+ Element Plus + lucide 图标;
节点树拖拽基于 SortableJS / vue-draggable-plus;
桌面壳为 Tauri(本仓库同时是 Tauri 应用,`npm run tauri dev`)。

## 开发

```bash
npm install
npm run dev          # 网页开发 (http://localhost:1420)
npm run tauri dev    # Tauri 桌面端
npm run build        # 类型检查 + 生产构建
```

推送到 `main` 会通过 GitHub Actions 自动部署到 Pages。
