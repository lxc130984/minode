# minode-beta

一个「节点树 = Lisp 表达式」的点击增量沙盒游戏。整个游戏同构于 Lisp 的 s 表达式：
**节点就是 symbol，嵌套就是括号嵌套，点击就是「eval 光标这里的 s 表达式」**。

- 父节点是函数，子节点是实参；**点击节点 = 对它做一次 eval**（只 eval 被点的那一个节点）。
- 返回值写在节点右边：`冶炼炉[铁]`；空手配方检测不通过显示 `[?]` 且不产出。
- **手持物 = 隐式实参**：选中背包物品（如斧头）再点击，手持物排在实参最前参与配方检测
  （手持斧头点森林 → 木材）。
- eval 不消耗任何东西：节点是 symbol，同一棵树可以无限点击；真正的成本是建造节点。
- **生产线经济（Mindustry 式）**：资产只有物品（背包，容量受限）；
  在**选择面板**选中节点类型 → 光标挂**虚影**进入放置模式 → 左键**消耗物品建造**
  （可连续建造，右键/Esc 取消）；`×` **回收**分解成原材料（默认返还 30%）。
- 配方产出全部是物品，进背包；物品与节点类型可同名（铁矿石既是物品又是实参节点）。
- 内容（物品/节点/配方/成本/数值）全部数据化，注册表装载；引擎保持小。

内置一条六层加工链 + 手持演示（斧头 × 森林 → 木材）+ 起始物资：

```
发动机厂[发动机]          ← 机械零件 + 钢
  装配台[机械零件]        ← 钢板 + 铁
    轧机[钢板]            ← 钢 + 铁
      锻炉[钢]            ← 铁 + 煤炭
        冶炼炉[铁]        ← 铁矿石 + 煤炭 + 氧气
          铁矿石  煤炭  氧气
```

## 当前进度

点击 = 单节点 eval（符号无响应，函数命中配方即产出物品进背包）；手持 = 隐式实参（D-25）；
返回值在结构变更时静态算出（「受影响节点 + 祖先链」增量重算）。
**生产线模型（D-26）**：物品背包（容量）+ 节点选择面板 + 放置模式（虚影/挤压预览/连续建造）+
回收全额返还 + 箱子（物品容器）。内置矿井 + 森林/斧头 + 六层加工链。
引擎 + 83 个单测、树渲染/折叠（语法高亮）、树内拖拽（零回流 + 单写者落位）、
localStorage 存档（v4，旧档按建造成本折算迁移）、撤销树（分叉 + 穿梭）。树为 Lisp 式渲染（括号显形嵌套、括号可拖整棵子表达式、兄弟 token 流式换行 + 悬挂缩进 + 自动折叠，D-29）。
性能基线：400 节点点击到下一帧 ≈ 1 帧。
下一步：成本曲线平衡、工具层级配方、图鉴与解锁。

## 开发

基于 Vite+ 统一工具链（`vp`）：

```sh
vp install          # 安装依赖
vp dev              # 开发服务器
vp check            # 格式 + lint
vp run type-check   # 类型检查（vue-tsc，必跑：vp check 不检查 .vue 脚本）
vp test             # 单元测试
vp run build        # 类型检查 + 生产构建
```

技术栈：Vue 3 + TypeScript + Pinia（单 store）+ vue-draggable-plus（嵌套拖拽）

- break_infinity.js（Decimal 大数）。
