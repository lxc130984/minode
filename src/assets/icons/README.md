# 图标目录(给美术)

把图片文件丢进这个目录,它就自动成为游戏里的图标——**不需要写任何代码**。

## 规则

- **文件名(去扩展名)= 图标键**。节点定义里 `icon: "文件名"` 引用它。
  例:`charcoal.png` → 这个物品的图标就是它。
- 支持 **png / webp / gif / svg / jpg**;推荐像素画 **16×16 或 32×32**。
- 渲染为 `image-rendering: pixelated`(像素风锐利放大),行内显示约 16px。
- **透明背景**效果最佳;文件名大小写敏感。
- **同名覆盖**:想替掉某个内置线条图标(如森林),放一张同名文件
  (`forest.png`)即可,不用改代码。

## 命名建议

- 与节点 id 一致(如物品"木炭"的节点 id 是 `charcoal`,图就叫 `charcoal.png`),
  定义和图标自然对应,注册时校验也会自动对上。

## 验证

放进文件后运行游戏(或刷新页面),打开右上角**图鉴**即可看到效果;
如果某个图标没出现,控制台会有 `[minode] 节点 "xx" 的图标 "yy" 未注册` 的提示。
